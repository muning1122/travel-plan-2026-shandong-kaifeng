公众号搜索：开封万岁山武侠城

12:00—13:20

午饭 → 酒店取行李

在酒店/龙亭附近吃饭，行李集中检查身份证、手机、充电宝、航班订单。

13:30—航班前

预订送机车：开封 → 郑州新郑机场

建议选18:30后从郑州新郑机场起飞的返广州航班。开封直达新郑机场的早班城际不适配下午航班，不当主方案。

导航：郑州新郑国际机场 T2

返程兜底航班取消/明显晚点先在航司App办改签；超过深夜再考虑机场/郑州东酒店，别疲劳折返开封。
本次收尾万岁山有夜场和上午两段体验；不再硬塞书店街白天暴晒和额外景点。
正常版上午万岁山，下午送机。
高温/晚点版不补景点，直接送机场。

交通接驳卡

车次和航班只作查票起点；付款前必须以航司、12306页面为准。

D1｜广州/佛山 → 青岛胶东

主选：广州白云飞青岛胶东；出票时优先选不太晚抵达的班次。

落地：带行李优先打车直达五四广场/浮山所；不安排落地后的远距离夜游。

D3｜青岛北 → 威海

参考车：2026年7月15日查到G6989，07:37—09:11，二等座97元/人。

预留：酒店到青岛北站60—90分钟；晚到威海就只在威高吃饭。

D6｜威海 → 郑州东 → 开封北

主选：上午从威海/威海南海出发的高速动车，郑州东同站换乘开封北，换乘留45—60分钟。

参考：2026年7月16日页面有08:09—14:23的G3428，二等座494元/人；D6实际车次、出发站和票价以12306为准。

D7｜开封 → 郑州新郑机场

主选：正规平台预订送机车，13:30出发更从容。

航班：优先18:30后从郑州新郑起飞的返广州航班。

D4—D5｜威海租车

取还：优先神州等正规平台和白天营业网点，提前确认保险、满油规则、停车点；D5最迟13:30完成还车。

新手边界：天气差、状态差、取车太晚就改打车；不去成山头，不开陌生海边夜路。

住宿订房助手

总共6晚：青岛2晚、威海3晚、开封1晚。

青岛｜五四广场/浮山所

住两晚：D1—D2；中心点浮山所地铁站/五四广场，半径1—1.5公里。

订房词：“浮山所地铁站 酒店”“五四广场 酒店”。

威海｜威高广场/幸福门

住三晚：D3—D5；中心点威高广场/幸福门，半径1—1.5公里，连续订同一房间。

避开：偏远海景房和难打车海边民宿；D6若从威海南海站出发，要提前核算送站车程。

开封｜万岁山/龙亭圈

住一晚：D6；龙亭湖西侧/万岁山2公里内或打车10分钟内。

重点：可寄存行李、靠主路、夜场结束后好打车。

统一筛选

评分4.5以上、可免费取消、有电梯、可寄存行李、靠近主路、评论里无明显隔音/卫生反复差评。

订完立即确认

入住/退房时间、前台是否24小时、是否可寄存、停车位和费用、火车站或景区打车是否方便。

景点执行卡｜全部换为对应实景

不爱爬山，所以所有路线按短走、遮阴、午休和可删点来排。

八大关 + 第二海水浴场 + 太平角

D2早晨｜树荫老建筑和海边，不需要登高。

走法：八大关南侧进入 → 树荫街区 → 第二海水浴场 → 太平角。时长：2.5—3小时。

避坑：不安排栈桥，不为每幢建筑排队，不在中午暴晒。

导航：青岛 八大关 第二海水浴场。

小麦岛（主推） + 石老人（备选）

D2下午｜小麦岛短停看海，石老人只在状态好时再加。

走法：先到小麦岛入口、草坪和近海平缓段，40分钟左右收；只有天气、体力和取车都合适时，才去石老人短停20分钟。

可删：石老人优先删。避坑：小麦岛夏天遮阴少、人多时不绕全岛；不再加雕塑园，也不赶黄岛跨海线。

威海环海路 + 猫头山3号观景台 + 火炬八街

D4主体验｜租车看海，不走猫头山徒步线。

走法：半月湾/海源公园 → 猫头山3号观景台短停 → 午休 → 火炬八街 → 国际海水浴场。

避坑：猫头山只开到观景点；雷雨、浓雾、大风就取消租车。

海源公园短看海

D5上午｜只看市区近海，给下午完整留白。

默认版：从酒店圈到海源公园短走海岸，10:30左右离开，再按租车订单还车。

可删：还车点在威海站、遇大风雷雨或身体疲劳时，上午整段删除，不为一个公园折返。

万岁山武侠城

D6傍晚 + D7上午｜本次分两段体验的主景点。

进园前：身份证、充电宝、水、轻便雨具；先在官方公众号看当天节目单。

走法：D6夜场排两三场核心演出；D7上午补昨天遗漏的节目。人气单项排队太长就换节目。

核对：票种、开园、夜场、节目单、二次入园和停车均以景区当期公告为准。

公众号/导航：开封万岁山武侠城

鼓楼夜市 / 书店街

只作开封味道备选，不挤占万岁山时间。

安排：只有D6到开封很早才考虑；否则完全不排。吃法：两人少量分灌汤包、炒凉粉、杏仁茶。

避坑：不把夜市排到D7返程前。

青岛四处候选｜可行性取舍

按 7 月高温、两晚青岛、不爬山和不赶网红人潮的原则筛过一遍。

主推加入

小麦岛公园

为什么值得：平缓草地、礁石和城市海景的组合，和八大关的老建筑不重复；不需要爬山，也适合下午短停。

怎么放：D2 午休后 16:30 左右去，只走入口、草坪和近海平缓段，40 分钟左右收。

硬边界：夏天遮阴少、周末/日落前易拥挤；不绕全岛、不追“孤独的树”排队，水和防晒必须带。

仅清晨可选

栈桥 + 圣弥厄尔大教堂

值不值：建筑和老城氛围值得看，但不是这条线的主体验；截图里的大量海鸥属于早春/冬季更常见的画面，7 月不要为海鸥专程去。

能怎么塞：只有想看老城建筑时，D2 07:00—08:15 做栈桥 20 分钟 + 教堂外观 20 分钟，再打车去八大关。

取舍：教堂室内受礼拜与现场参观安排影响，只把外观当默认；想睡足或天气闷热，就整段删掉。

不建议本次排

崂山风景区

为什么不排：它本身很好，但需要半天到一天，还涉及预约限流、景区接驳和山海步行，和“两晚青岛、避热、不爬山”的目标相冲突。

正确打开方式：留到下一次单独青岛 3—4 天游，再选太清或仰口一条线；不要在 D2 用一半体力换一个仓促版本。

当前结论：这次明确删掉，不作为雨天或临时加项。

顺路备选

石老人海水浴场

定位：比栈桥更适合“开车短停看海”，但没有必要和小麦岛、雕塑园做三连打卡。

何时去：D2 小麦岛后，天气舒服、车况和体力都好才短停 20 分钟；不下海、不走远沙滩。

删法：一旦出发晚、堵车、太阳强或人累，优先删石老人，路线仍然完整。

旅行管家最终排法：D2 默认“八大关 → 二浴 → 午休 → 小麦岛”。想看老城建筑，就清晨额外加栈桥 + 教堂外观；崂山不纳入本次行程；石老人永远是可删加项。

景点内部执行攻略

进门前带什么、先看哪里、累了删什么，全部按不爬山和避高温安排。

青岛八大关怎么走？

八大关 → 第二海水浴场 → 太平角

入园前：防晒、水、舒服鞋、充电宝；早上出发，别等太阳最晒。

入口与路线：导航“青岛 八大关 第二海水浴场”，从南侧靠海一端进入，先走树荫老建筑，再到二浴，最后太平角短停。

必看：树影、老建筑与二浴海岸。可删：太平角；不要为单栋建筑排队。

离开：11点前结束，打车回五四广场/浮山所午饭和午休。

威海沿海自驾怎么走？

半月湾 → 猫头山3号观景台 → 午休 → 火炬八街 → 国际海水浴场

取车前：核对驾照、车况、胎压、油量、保险、还车规则和停车位；手机满电，车内放水和纸巾。

执行：每一站只停20—30分钟；猫头山只到观景台附近，不走徒步线。中午必须回酒店避晒。

必看：半月湾海色、猫头山公路视角、火炬八街街口。可删：大风、雷雨、取车太晚时全部取消租车，改商圈和酒店休息。

离开：天黑前回主路还车/停车，不为日落走陌生海边夜路。

威海D5自由日怎么选？

市区近海短停，下午完整休整

出发前：看风力、降雨、驾驶状态和D6车票；手机满电，车上带水、防晒和纸巾。

正常版：07:40左右去海源公园短看海；若还车点在威海站方向，就直接删掉本段，不增加折返。

下午：13:30前完成还车，14:00—17:30按独立页面执行。地点超出上午最后一站或还车点7公里就换近距离备选。可删：天气差就删上午海边。

离开：18:00附近吃清淡晚饭，回酒店整理行李，20:30前休息。

万岁山两段怎么安排？

D6夜场看重点，D7上午补遗漏

入园前：身份证、充电宝、水、纸巾、轻便雨具；先在官方公众号看当天节目单、票种和夜场信息。

执行：D6只排两三场核心演出，排队太长直接换场；D7上午补昨日没看成的节目与轻拍照。

必看：以当天节目单的主舞台与夜场为先。可删：边缘区、排队过长项目和额外夜市。

天气/体力：高温只走遮阴和短距离路线；下雨按景区当天公告调整，别为看全场硬撑。

每天吃什么｜不绕路、不排过度网红店

具体店铺营业和排队会变，优先用关键词找路线内评分稳定的店。

青岛｜D1—D2

吃：鲅鱼水饺、海鲜水饺、家常海鲜。

搜：“浮山所 海鲜水饺 评分4.5以上”。

威海｜D3—D5

吃：鲅鱼水饺、海菜包子、烤鱿鱼、小海鲜。

搜：“威高广场 鲅鱼水饺”“韩乐坊 海菜包子”。不点游客海鲜套餐，D5不喝酒。

开封｜D6—D7

吃：灌汤包、桶子鸡、羊肉炕馍、杏仁茶、炒凉粉。

原则：D6到店晚就先吃酒店附近简餐；夜市每样少量分着吃，不喝酒后赶车。

餐饮原则

正餐以家常菜、小吃搭配为主，海鲜只做一顿小尝鲜；每次不点太满，转场日以轻食和面食为主。

排队替代

超过30分钟直接搜“当前位置 + 目标菜 + 评分4.5以上”，限定步行10分钟，不为一间店绕城。

出发前准备清单

按类别收进一个轻便背包，转场时不反复翻行李。

证件与订单

  • 身份证、航班订单、12306订单、酒店订单。
  • 万岁山票务/节目单截图、租车订单。
  • 三城酒店前台电话与寄存行李说明。

海边与租车

  • 驾驶证、防晒霜、帽子、墨镜、舒服鞋。
  • 水、纸巾、湿巾和车载数据线。
  • 取车时拍全车视频，确认油量和外观。

高温与下雨

  • 折叠伞/雨衣、薄外套、充电宝。
  • 防暑用品、创可贴、晕车药和常用药。
  • 每个海边点只带小包，别背大行李。

应急替代方案

晚点、下雨、太累时直接删改，不临场硬扛。

D1 航班晚点怎么办？

直接去青岛酒店入住；取消所有夜景，只在酒店步行范围吃饭。不要在陌生城市晚到后再赶海边。

D3 / D6 高铁晚点怎么办？

D3抵达后只保酒店和附近晚餐；D6晚到开封就取消当晚万岁山，直接入住，D7上午再看核心节目。转场日不补景点。

D4 大风、雷雨或状态差怎么办？

取消租车，改威高广场吃饭和酒店午休；天气转好再短走幸福门。新手不在雨雾海边试路。

D6 换乘不顺或赶不上夜场怎么办？

优先选郑州东留足45—60分钟的下一组衔接；到开封超过18:30就不硬赶夜场，直接吃饭休息，D7上午补核心节目。

万岁山高温或下雨怎么办？

先看官方节目单，优先遮阴和短距离项目；高温不把园区走遍，下雨按景区公告换场或缩短停留。

D7 航班晚点或取消怎么办？

先在航司 App 改签；明显晚到再订机场或郑州东附近酒店。返程日不补开封景点，也不疲劳折返。
